Check out our new paper on hyperspectral drillcore scanning! We present a new (open-source!) workflow for real-time processing and analysis of hyperspectral data, with a specific focus on its application to mineral exploration through drill core scanning.

Current hyperspectral drillcore analysis methods typically involve a significant delay between data acquisition and analysis, which limits the value of these rich datasets in time-critical exploration decisions. To help address this, we have developed two software frameworks, "[crunchy](https://github.com/hifexplo/crunchy)" and "[hycore](https://github.com/hifexplo/hycore)". *Crunchy* facilitates real-time preprocessing, correction, and analysis of hyperspectral data, while *hycore* manages and stores the data in a consistent structure, enabling interactive visualization, analysis, and mosaicing.

We demonstrate the framework's capabilities using data from several sediment-hosted base metal deposits. The real-time results enabled rapid identification of key minerals, informed sampling strategies. We conclude that such real-time data could greatly inform geological logging activities and help ensure maximum information is extracted from valuable drillcores, in a reproducible and objective way.
