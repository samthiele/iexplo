This is Elias Arbash, a Mechatronics Engineer with double masters in Mechatronics and Intelligent Systems. I am doing my Ph.D. in imagery data fusion using machine learning and deep learning with a goal of developing a high-level controller for a robotic arm. My main tasks involve data preparation, cleaning, and preprocessing of RGB and hyperspectral data for subsequent processing with deep learning models such as object detection and segmentation, in real time. I am aiming at building processing routines for conveyor-belt scenarios that can combine high spatial resolution RGB and high spectral resolution HSI. I utilise high-performance computers with Python and parallel processing techniques.
